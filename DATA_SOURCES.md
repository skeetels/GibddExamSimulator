# Источник и воспроизводимость банка AB

Единственный канонический банк проекта находится в `assets/question-bank/ab`. Обе клиентские сборки включают его в output автоматически; копии банка в исходниках клиентов не хранятся.

## Состав

```text
Категория:          A/B/M (в коде AB)
Вопросы:            800, ID 1–800
Билеты:             40 × 20
Тематические блоки: 160 × 5
Изображения:        548 JPEG
Размер JPEG:        32 237 906 байт
```

Авторитетная страница: `https://xn--90adear.xn--p1ai/mens/avtovladeltsam/abm`.

Для воспроизводимого транспорта использован зафиксированный снимок `etspring/pdd_russia`:

```text
tag:         v2026.Q2.0
commit:      5cf625ee7e494a17c143527862b45d8020871882
commit date: 2026-06-17T14:27:16+03:00
```

Сведения об официальной странице, снимке, времени генерации, количестве и SHA-256 JSON находятся в `bank-manifest.json`.

## JPEG

Исходные изображения были декодированы и сохранены как обычный JPEG. Валидатор проверяет сигнатуру `FF D8 FF`, существование каждой ссылки, отсутствие лишних файлов и точный суммарный размер. В итоговом банке нет WebP-файлов и нет WebP-содержимого под расширением `.jpg`.

## Проверка

```powershell
python .\tools\build_ab_question_bank.py --validate-only
```

Проверяются точные количества, ID, структура билетов и блоков, ответы, изображения, `imageBytes` и SHA-256 `official-questions.json`. Категория C/D, её изображения и UI в версии 2.0.4 отсутствуют.

Для повторного построения из подготовленного снимка:

```powershell
python .\tools\build_ab_question_bank.py \`
  --source-json C:\path\official-questions.json \`
  --source-images C:\path\Images \`
  --output .\assets\question-bank\ab
```
