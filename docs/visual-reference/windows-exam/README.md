# Визуальная регрессия Windows-экзамена

## Эталон 1.2.0

Распакуйте GibddExamSimulator-Source-1.2.0.zip в отдельный каталог и сначала сравните восемь SHA-256 из docs/DESKTOP_EXAM_VISUAL_CONTRACT.md. Собирать эталон следует без изменения XAML. Запустите его с тем же банком и одинаковым ФИО кандидата.

## Состояния

Для эталона и 2.0.3 сохраните PNG с одинаковым разрешением и scaling:

~~~text
01-overview-20.png
02-question-with-image.png
03-question-without-image.png
04-selected-not-confirmed.png
05-confirmed.png
06-supplementary.png
07-result.png
08-review-errors.png
~~~

Порядок воспроизведения 2.0.3: Главная → Подготовка → Готов; Space открывает вопрос, 1–5 выбирает, ОТВЕТИТЬ подтверждает, Esc возвращает перечень. Для supplementary намеренно подтвердите одну ошибку, затем завершите основной блок. После результата откройте Просмотр ошибок.

## Матрица захвата

Повторите восемь состояний минимум для 1366×768/100%, 1920×1080/125% и 2560×1440/150%. Не масштабируйте PNG после захвата. Проверяющий сопоставляет границы строк, шрифт, порядок элементов, пропорции изображения, состояния кнопок и факт отсутствия modern navigation.

Автоматический pixel-diff WPF не включён: результат зависит от ClearType, GPU и DPI. Вместо ненадёжного порога CI использует DesktopExamVisualContractTests, а эта матрица остаётся обязательной ручной проверкой. Фактический smoke 2048×1152/125% выполнен 2026-09-01 и описан в docs/TEST_MATRIX.md.
