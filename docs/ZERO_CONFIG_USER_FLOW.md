# Путь пользователя без настройки

## Первый компьютер

1. Запустить `GibddExamSimulator-Setup-2.0.4-win-x64.exe` и завершить обычную установку.
2. Открыть программу. Она сама создаст безопасную техническую identity и покажет QR-код с подписью `Откройте приложение на телефоне и отсканируйте этот код один раз`.
3. Пока телефона нет, можно выбрать `Продолжить пока без телефона`: экзамен и локальная история уже работают offline.

## Первый телефон

1. Установить `GibddExamSimulator-2.0.4-android.apk` или открыть опубликованную PWA.
2. Нажать одну большую кнопку `Открыть камеру`. Разрешение камеры запрашивается только в этот момент.
3. Навести камеру на QR компьютера. При сломанной камере можно ввести короткий одноразовый код.
4. Дождаться сообщения `Устройства связаны` на обоих экранах.

На следующих запусках onboarding пропускается. Завершённые результаты, прошлые ошибки и время ответов отправляются автоматически. При отсутствии сети показывается `Офлайн — отправим позже`; ручной адрес сервера не требуется.

## Дополнительный телефон и отзыв

На главной странице компьютера выбрать `Подключить новый телефон` и отсканировать новый QR. В `Подключённых устройствах` видно понятный тип и последнюю активность. `Отвязать устройство` отзывает только выбранное. `Сбросить синхронизацию` всегда сначала показывает предупреждение и не удаляет локальные экзамены.

## Telegram

`Подключить Telegram` открывает фиксированного бота с одноразовым deep-link. После `/start` личный профиль связывается с владельцем, а экзаменационные отчёты отправляются автоматически. Chat ID, bot token и выбор другого бота пользователю не показываются.
